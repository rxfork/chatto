## AssetService

Reads room-scoped asset metadata and freshly signed asset URLs.

<a id="chatto-api-v1-AssetService-OpenBurnAttachment"></a>

### OpenBurnAttachment

Deliberately opens one session. Membership and current message-read access
are required. Audio uses its verified duration; video adds 10 seconds to
its verified duration to press Play. Other files use the configured limit.
Missing media duration returns failed_precondition without claiming a
session. Timers start on Open and continue during buffering or pauses.

```http
POST /api/connect/chatto.api.v1.AssetService/OpenBurnAttachment
```

<a id="chatto-api-v1-OpenBurnAttachmentRequest"></a>

#### Input: OpenBurnAttachmentRequest

Starts or retries one logical session. Generate a random session_id before
the first attempt and reuse it only for retries of that opening. Closing,
expiry, or an attempt with a different ID cannot restore a consumed session.

| Field | Type | Description |
| --- | --- | --- |
| `room_id` | `string` | Required. Room containing the owning message. |
| `asset_id` | `string` | Required. The burn attachment's source asset ID. |
| `session_id` | `string` | Random capability for this opening. Reuse only to retry the same session. |


<a id="chatto-api-v1-OpenBurnAttachmentResponse"></a>

#### Result: OpenBurnAttachmentResponse

Metadata and byte URLs after the session is committed.

| Field | Type | Description |
| --- | --- | --- |
| `asset` | [`Asset`](/reference/connectrpc-api/types/#chatto-api-v1-Asset) | Session-bound URLs. Do not persist, prefetch, or share them. |
| `view_expires_at` | `google.protobuf.Timestamp` | Clear displayed content at this deadline, even while offline. |

### CloseBurnAttachment

End on viewer close, navigation, or privacy reset. A lost close is bounded
by the original session deadline; it does not create a new session.

```http
POST /api/connect/chatto.api.v1.AssetService/CloseBurnAttachment
```

<a id="chatto-api-v1-AssetService-GetAsset"></a>

### GetAsset

Reads one asset. Authentication and room membership are required.
Assets also require message.read or a matching thread relationship with
message.read-interactions. Returns NOT_FOUND when the asset is missing,
deleted, or owned by a
different room.

```http
POST /api/connect/chatto.api.v1.AssetService/GetAsset
```

<a id="chatto-api-v1-GetAssetRequest"></a>

#### Input: GetAssetRequest

Request to read one room-scoped asset with freshly signed URLs.

| Field | Type | Description |
| --- | --- | --- |

| `asset_id` | `string` | Required. Asset ID. |
| `thumbnail` | [`ImageTransformOptions`](/reference/connectrpc-api/types/#chatto-api-v1-ImageTransformOptions) | Thumbnail URL options. Defaults are applied when absent. |

<a id="chatto-api-v1-AssetService-BatchGetAssets"></a>

### BatchGetAssets

Reads many assets in one room. Authentication and room membership are
required. Assets also require message.read or a matching thread
relationship with message.read-interactions. Missing, deleted, wrong-room, and inaccessible asset
IDs are omitted. Results preserve first-seen request order, and repeated
asset IDs are de-duplicated.

```http
POST /api/connect/chatto.api.v1.AssetService/BatchGetAssets
```

<a id="chatto-api-v1-BatchGetAssetsRequest"></a>

#### Input: BatchGetAssetsRequest

Request to read many room-scoped assets with freshly signed URLs.

| Field | Type | Description |
| --- | --- | --- |
| `room_id` | `string` | Required. Room that owns the assets. |
| `asset_ids` | `repeated string` | Required. Asset IDs. Missing, deleted, and wrong-room asset IDs are omitted. |
| `thumbnail` | [`ImageTransformOptions`](/reference/connectrpc-api/types/#chatto-api-v1-ImageTransformOptions) | Thumbnail URL options. Defaults are applied when absent. |
